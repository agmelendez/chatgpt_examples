# Simple Profile Page

Files:
- `index.html` — main page
- `styles.css` — styling
- `script.js` — small interactive features (theme toggle, copy email, download CV)
  
How to use:
1. Save all files to the same folder.
2. Open `index.html` in your browser.
3. Edit the content (name, bio, skills, links) directly in `index.html`.
4. Replace the avatar URL or point it to a local image if you prefer.
